# Demo media

Made by `scripts/build_demo_media.py` from the sample galleries (pages from `samples/`, CC0-1.0) and by a Playwright screenshot of `ugoku serve`
showing a sample page.

- `webui-*.png`: screenshots of this project's web UI with a CC0 sample page. Same licence as the samples (CC0-1.0).
- `*-p0?.gif`, `*-p0?.png`: the composited moving page. The page art, lettering and layout are CC0-1.0 (`samples/LICENSE`). The panel motion comes from clips
  generated with MiniMax H3; whatever terms MiniMax attaches to H3 output apply to that part, not the CC0 dedication.

The files are listed in `samples/MANIFEST.sha256` so the repository policy check (`scripts/check_repo.py`) can verify them.
